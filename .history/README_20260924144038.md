# Garibook

> A premium mobility and car-rental experience for comfortable travel across Bangladesh.

**Live 
Link :** https://garibook-topaz.vercel.app/ 


## Overview

Garibook is a responsive React application inspired by modern chauffeur and intercity travel services. It combines a premium visual experience with practical booking flows, vehicle discovery, route browsing, and transparent pricing.

The interface is designed for both quick bookings and detailed trip planning, with support for English and বাংলা, BDT and USD pricing, and mobile-first interactions.

## Highlights

- Three hero experiences: Luxe Skyline, Smart Console, and VIP Split
- Animated Dhaka-inspired skyline with day, sunset, and night modes
- Search and booking flow for airport transfers, hourly rentals, intercity trips, tours, and bus or launch hubs
- Vehicle fleet browser with category filters and detailed specification modal
- Popular Bangladesh routes including Cox's Bazar, Chittagong, Sylhet, Rajshahi, and the Padma Bridge corridor
- Multi-step chauffeur booking flow with passenger details, pricing, promo codes, and assignment simulation
- Bilingual interface with English and বাংলা support
- Live currency toggle between BDT and USD
- Responsive navigation, mobile quick actions, scroll animations, and custom hover interactions

## Run Locally

### Requirements

- Node.js 18 or later
- npm

### Setup

```bash
git clone <your-github-repo-url>
cd garibook-frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Commands

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run preview  # Preview the production build locally
npm run lint     # Run the TypeScript check
```

## Booking Experience

1. Choose a service, route, or vehicle.
2. Add trip details, date, time, and passenger information.
3. Review the calculated fare and optional promo code.
4. Confirm the request and view the simulated chauffeur assignment.
